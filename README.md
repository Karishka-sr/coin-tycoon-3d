# Coin Tycoon 3D

3D-игра в жанре «тайкун» на LibGDX: бегаешь по арене, собираешь монеты и
вкладываешь их в улучшения, которые ускоряют следующий заход.

Геймплей и интерфейс написаны на **Kotlin**, графика и игровой мир
(процедурные модели, арена, монеты) — на **Java**.

## Что уже есть (первая версия)

- Меню: Играть, Мир блоков, Настройки, Магазин, Выход.
- 3D-сцена: земля, дорожка, забор, городок из домов, мягкий свет.
- Вид от первого лица: камера на высоте глаз, покачивание при беге.
- Поворот камеры: мышь, свайп по экрану, клавиши Q/E и стрелки.
- Монеты: спавн по таймеру, вращение, парение, магнит, подбор.
- Тайкун-экономика: 7 линий апгрейдов, растущая цена, пассивный доход.
- Мир блоков: процедурный воксельный ландшафт 64×48×64 — холмы, вода,
  пляжи, деревья и руды по глубине. Копание и установка блоков, хотбар,
  гравитация и прыжок, режим полёта. За каждый добытый блок платят монеты,
  поэтому экономика общая с ареной, а правки мира сохраняются между запусками.
- Сохранение прогресса и настроек в JSON.
- Звук: эффекты синтезируются в коде (WAV в памяти), без звуковых файлов.
  Подбор монеты и крупной монеты, покупка и отказ, клики в меню и HUD;
  громкость и выключение звука — в настройках.
- UI на Scene2D: счётчик монет, прицел и магазин улучшений (Tab).
- Управление: WASD / стрелки на десктопе; на Android — плавающий джойстик
  в левой половине экрана, поворот камеры — свайпом по остальной части.
  В мире блоков: ЛКМ — копать, ПКМ — ставить, Space — прыжок, F — полёт,
  цифры и колесо — выбор блока в хотбаре.

Вся геометрия строится в коде, внешних моделей и текстур нет. Единственные
ассеты — два шрифта DejaVu (нужны для кириллицы в интерфейсе). Звуковые
эффекты тоже генерируются кодом, поэтому звуковых файлов в проекте нет.

## Структура

```
core/      — общий код игры (Kotlin + Java), не зависит от платформы
lwjgl3/    — десктопный запуск
android/   — Android-модуль (сборка APK)
assets/    — шрифты
```

Java-часть: `ModelFactory`, `MaterialFactory`, `Arena`, `CoinData`, `CoinField`,
`SoundSynth`, `SfxId`, воксельный мир (`com.tycoon.voxel`: `BlockType`,
`VoxelWorld`, `TerrainGenerator`, `VoxelRaycast`, `BlockGeometry`, `VoxelPlayer`,
`VoxelInventory`).
Kotlin-часть: экраны (меню, настройки, магазин, игра, мир блоков), рендереры,
игрок, камера от первого лица, ввод, джойстик, экономика, UI, `SoundBank`.

## Требования

- JDK 17+
- Android SDK (для сборки APK): platform 34, build-tools 34.0.0

## Десктоп

```bash
./gradlew lwjgl3:run
```

Тесты логики (экономика, монеты, границы арены):

```bash
./gradlew core:test
```

Тесты камеры тянут нативную часть LibGDX, поэтому в `core` подключены
`natives-desktop` — сами тесты OpenGL не трогают.

## Android (APK)

**Готовый APK:** скачать из [последнего релиза](https://github.com/Karishka-sr/coin-tycoon-3d/releases/latest).

Сборка из исходников. Укажите путь к SDK в `local.properties`:

```properties
sdk.dir=/path/to/android-sdk
```

Сборка debug-APK:

```bash
./gradlew android:assembleDebug
```

Готовый файл: `android/build/outputs/apk/debug/android-debug.apk`.
В APK попадают нативные библиотеки LibGDX для armeabi-v7a, arm64-v8a, x86 и
x86_64, поэтому он запускается и на устройстве, и в эмуляторе.

## Управление

| Действие | Клавиатура | Android |
| --- | --- | --- |
| Движение | WASD / стрелки | джойстик в левой половине |
| Поворот камеры | мышь (перетаскивание) / Q, E / стрелки | свайп по экрану |
| Магазин | Tab | кнопка «Закрыть» в панели |
| Выход в меню | Esc | кнопка «Меню» справа сверху |

## Меню

- **Играть** — заход на арену; прогресс общий для меню и игры.
- **Настройки** — чувствительность обзора, инверсия вертикали, показ прицела
  и джойстика, громкость и выключение звука; сохраняются сразу при изменении.
- **Магазин** — те же апгрейды, что и в игре, можно покупать до захода.
- **Выход** — закрывает приложение.

## Улучшения

Ценность монет, скорость спавна, магнит, вместимость арены, пассивный доход,
скорость бега, удача (шанс крупной монеты).
